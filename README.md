# 🧠 Cognitive Assist

AI-powered IoT system designed to help Alzheimer’s and dementia patients recognize people, recall interactions, and stay safe in real time.

---

## 🚀 Features

- 🔍 Real-time Face Recognition
- 🧠 Memory Recall (Name, Relation, Past Interaction)
- 💬 AI-generated Conversation Summaries (LLM)
- 📍 GPS-based Geofencing Alerts
- 📊 Caregiver Dashboard (Monitoring & Logs)

---

## 🏗️ System Overview


Camera → Face Recognition → Memory Retrieval → Display → Database → Dashboard


- Face detection using OpenCV / Face-API.js  
- AI processing with TensorFlow + LLM (Ollama/Qwen)  
- Backend with Django REST API  
- Data stored in MongoDB  
- Frontend dashboard built using React

## 📸 Demo Flow

1. Camera detects a face  
2. System recognizes the person  
3. Displays:
   - Name  
   - Relationship  
   - Last interaction  
4. Saves interaction automatically  
5. Updates caregiver dashboard
